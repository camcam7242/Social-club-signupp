# Fable

A social club sign-up website. Members can join Fable by entering their name, email, phone number, interests, and a password.

## Files

- `index.html` — the sign-up page
- `styles.css` — page styling
- `script.js` — form handling (shows a success message on sign-up)

## Running it

Open `index.html` in a browser, or serve the folder with any static file server.
